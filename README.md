# naruto-rise-of-a-ninja-nx

A Nintendo Switch (homebrew NRO) port of *Naruto: Rise of a Ninja* (Xbox 360) by static recompilation with ReXGlue.
Work in progress: stage 1 (files and inspection). See [docs/port-journal.md](docs/port-journal.md).

- PC base: [jorjbarbosa/naruto-rise-recomp](https://github.com/jorjbarbosa/naruto-rise-recomp) (GPL-3.0).
- Switch template: [ChanseyIsTheBest/sa2-nx](https://github.com/ChanseyIsTheBest/sa2-nx) (GPL-3.0); renderer reNut
  by masterspike52 on plume's deko3d back end.

No game data, recompiled code or shaders made from the game are in this repository. You need your own copy of the game.
