Do not read this directory during routine onboarding or a normal task. Open a specific file only to answer a concrete historical question, cite its date and verify any claim against current source or a new run before acting.

- Historical investigations: `cpu-bottleneck-analysis-and-solutions.md`, `port-journal.md`, `konoha-optimization-log.md`, `culling-solutions-log.md`.

- Historical pre-0.1.5 pilot runs: `runs/` (`pilot-village-view-001`, `pilot-village-view-002`, `village-view-1`).
