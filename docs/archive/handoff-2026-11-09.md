## 2. Key Optimizations & Changes Implemented

### A. Upstream ReXGlue SDK & CPU TLB Optimizations (Run 7)
1. **2 MB Page Alignment for 512 MB Guest Memory Window:**
   - Files: `sdk/src/core/guest_memory_switch.cpp`, `guest_memory_switch.h`, `memory_switch.cpp`.
   - Ported 2 MB alignment (`virtmemFindAslr(size + 2MB, 2MB)` + `AlignUp(found, 2MB)`) from `sa2-nx` v1.0.6 (`baf523b`).
   - Enables Horizon OS ARM64 L2 2MB block descriptors (huge pages) for the 512 MB guest address space.
2. **NRO `.text` and `.rodata` 2 MB Huge Page Remapping:**
   - File: `sdk/src/ui/switch_code_blocks.cpp`, registered in `sdk/cmake/rexglue_switch.cmake`.
   - Remaps the 38 MB `.text` and `.rodata` segments to 2 MB-aligned pages on startup, eliminating I-TLB thrashing across guest calls.
3. **Indirect Function Dispatcher Optimization:**
   - Files: `sdk/include/rex/system/function_dispatcher.h`, `sdk/src/system/function_dispatcher.cpp`.
   - Replaced linear array scanning with a 16-entry direct-mapped thread-local cache `(guest_address >> 2) & 15`.
4. **Permanent Flush-to-Zero (FZ/FZ16) & Default NaN (DN):**
   - Files: `sdk/include/rex/platform/fpscr.h`, `sdk/include/rex/ppc/context.h`.
   - Permanently enabled on ARM64 Switch, eliminating pipeline-flushing `msr fpcr` instructions.
5. **Measured Impact (Run 7):**
   - `Main XThread` CPU utilization dropped from **~95%** down to **33.4%** (with 69% kernel idle wait). CPU simulation bottleneck was fully eliminated.

### C. GPU & Render Thread Optimizations (Run 8 & Run 9)
1. **Tiling Resolve Storm Collapsing:**
   - File: `app/src/renut_engine/gpu/d3d/hooks/draw.cpp`.
   - Xbox 360 sub-tile resolves (0 and 1) are suppressed in `NarutoResolve` (`sub_821398C8`), and the final resolve is collapsed into a single whole-screen resolve `(0, 0, width, height) -> (0, 0)`.
   - Eliminates 66% of all fullscreen resolve draws, pipeline state resets, and memory flushes.
2. **Clear Repeat Skipping (`sa2_renut_clear_repeat`):**
   - Files: `app/src/renut_engine/gpu/render/surfaces.h`, `app/src/renut_engine/gpu/render/draw.cpp`.
   - Ported repeated whole clear check from `sa2-nx` v1.0.4 (`32a81a8`). Identical whole clears of color and depth/stencil targets are not re-sent to the GPU.
3. **Elimination of Telemetry Allocations on Core 2:**
   - File: `app/src/renut_engine/gpu/d3d/hooks/draw.cpp`.
   - Guarded per-item `std::unordered_map` insertions and heap node allocations in `sub_820FD5F8` behind `naruto_diag_draw_telemetry = false`.
   - Eliminates 1.5–2.5 ms of heap churn on Core 2 (`T_820F02C0`).
4. **Lock-Free Bounded Ring Queue (`sa2_renut_lockfree_queue`):**
   - File: `app/src/renut_engine/gpu/backend/render_thread.cpp`.
   - Ported Dmitry Vyukov's 16,384-slot bounded MPMC queue with `alignas(64)` cache line separation.
   - Eliminates `std::mutex` lock contention and `std::vector` dynamic reallocations between Core 2 and Core 1 across 3,200+ draws/frame.
   - Added `sa2_renut_batch_clock` and `sa2_renut_wake_batch = 16` with slot prefetching (`kRingAhead = 8`).
5. **Deko3d Fastpath Expansion for Modular Geometry:**
   - File: `app/src/renut_engine/gpu/render/draw.cpp`.
   - Expanded `can_fastpath` in `DrawStateLocked` to allow Chunks 27, 56 (VertexDeclaration), 68 (Textures 2..17), and 32-byte texture validation (`tex_bytes[32]`).
   - Short-circuited `PushFloatConstants(ps)` and `PushFloatConstants(vs)` when constants are clean between submeshes.
   - Raises fastpath hit-rate on the 2,138 modular draws (`Top Mat 0x40fbab80`) to >90%, reducing draw driver time from 10.4 µs to ~2.8 µs per draw.
